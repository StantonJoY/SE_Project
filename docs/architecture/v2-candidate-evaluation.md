# V2 候选方案评估（AI proxy 技术评审，正式人工验收待完成）

来源：原 19 条 V2 需求、docs/plans/V2-execution.md、ADR-005；评审不声称具名人工批准。

| 候选 | 优点 | 不满足的约束 / 代价 | 本地决策 |
|---|---|---|---|
| LLM 直接给胜者、价格、花费 | 接入简单 | 破坏 ARCH-012 权限边界，数学与预算无法确定重放 | 拒绝 |
| 确定性引擎 + 每请求内存预算 | 离线纯逻辑清晰 | 重启/跨请求重置，无法保证幂等与支出守恒 | 拒绝 |
| JSON 账本 + JSONL 独立双写 | 格式可读 | 两次写入不能原子提交，账务/证据分叉 | 拒绝 |
| SQLite 同库预算/结果/审计 + 纯数学竞价 | 标准库、跨连接事务、唯一请求、重启恢复可测试 | 本地单机并发与磁盘可用性限制；不是实际支付/曝光 | 采用 ADR-005 本地方案 |

pay_as_bid 与 relevance_times_bid 是唯一验证的命名策略，配置不得包含可执行公式。低余额候选过滤与事务内复检并用。合规在结算前，审计与扣费同事务，未知提交状态明确暴露。若引入多赢家、真实曝光、充值或外部支付，重开 ADR 与事件语义。

真实 HTTP 提供者使用注入的标准 chat-completions 端点；固定分数仅供离线确定性测试。默认 2000 上下文预算及超限拒绝用于保留 standing constraints；真实服务质量/费用必须另做 live 验证。
